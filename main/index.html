Giới thiệu về HTML

HTML (Hypertext Markup Language) là ngôn ngữ đánh dấu siêu văn bản dùng để tạo cấu trúc trang web.

Nội dung tập tin HTML chứa các thẻ (tag) trình bày hình thức và nội dung của trang.

Giới thiệu về CSS

CSS (Cascading Style Sheets) giúp định kiểu màu sắc, font chữ và bố cục giao diện cho trang web.

Giới thiệu về JavaScript

JavaScript là ngôn ngữ kịch bản tạo ra các tương tác động linh hoạt cho người dùng trên web.

Giới thiệu về JQuery

JQuery là thư viện JavaScript viết sẵn giúp đơn giản hóa việc xử lý sự kiện và hiệu ứng web.
